示例一：公历转农历（完整推演）

任务：将2024年5月8日转换为农历日期

步骤1：确定农历年份

查表：2024年春节 = 2024-02-10

判断：

• 公历日期 2024-05-08

• 春节日期 2024-02-10

• 因为 5月8日 > 2月10日

结论：农历年份 = 2024年

步骤2：获取农历编码

查表：2024年编码 = 0x0a974

解析编码：

0x0a974 = 0000 1010 1001 0111 0100

步骤1：闰月 = (0x0a974 >> 12) & 0xF = 0x0 = 0
        → 2024年无闰月

步骤2：基础天数 = 0x0a974 & 0xFFF = 0xa974 = 1010 1001 0111 0100

步骤3：计算每月天数
正月: 29 + (0) = 29天（Bit 0 = 0）
二月: 29 + (1) = 30天（Bit 1 = 1）
三月: 29 + (0) = 29天（Bit 2 = 0）
四月: 29 + (1) = 30天（Bit 3 = 1）
五月: 29 + (1) = 30天（Bit 4 = 1）
六月: 29 + (0) = 29天（Bit 5 = 0）
七月: 29 + (1) = 30天（Bit 6 = 1）
八月: 29 + (1) = 30天（Bit 7 = 1）
九月: 29 + (1) = 30天（Bit 8 = 1）
十月: 29 + (0) = 29天（Bit 9 = 0）
十一月: 29 + (1) = 30天（Bit 10 = 1）
腊月: 29 + (0) = 29天（Bit 11 = 0）

2024年农历各月天数：
29+30+29+30+30+29+30+30+30+29+30+29 = 355天

步骤3：计算距春节天数

春节日期：2024-02-10
目标日期：2024-05-08

2月剩余天数：29 - 10 = 19天（2024年为闰年，2月有29天）
3月天数：31天
4月天数：30天
5月前8天：8天

距春节天数 = 19 + 31 + 30 + 8 = 88天

步骤4：推算农历月日

逐月累加天数：

正月：29天，累计29天
  88 >= 29，继续

二月：30天，累计59天
  88 >= 59，继续

三月：29天，累计88天
  88 = 88，恰好进入三月最后一天

距春节天数 = 88（正月初一=第0天）
三月起始累计 = 59（正月至二月）
三月内第几天 = 88 - 59 = 29（三月第29天）
农历日 = 29 + 1 = 30（正月初一=第1天）

农历月 = 三月
农历日 = 三十

最终结果

公历2024年5月8日 = 农历2024年三月三十

示例二：农历转公历（完整推演）

任务：将农历2024年四月十五转换为公历日期

步骤1：确认农历年

农历年份：2024年（题目已给）

步骤2：查表获取春节日期

查表：2024年春节 = 2024-02-10

步骤3：获取农历编码并解析

编码：0x0a974（2024年）

解析结果（与示例一相同）：

• 无闰月

• 正月29天，二月30天，三月29天，四月30天...

步骤4：计算目标日期在农历年内的位置

农历日期：四月十五

正月：29天
二月：30天
三月：29天
四月初一到四月十五：15天

距春节天数 = 29 + 30 + 29 + (15 - 1) = 29 + 30 + 29 + 14 = 102天

（加14是因为四月十五距离四月初一是14天）

步骤5：计算公历日期

春节日期：2024-02-10
加102天

2月剩余：29 - 10 = 19天（2月有29天）
3月：31天
累计：19 + 31 = 50天
4月：30天
累计：50 + 30 = 80天
5月：需要 102 - 80 = 22天

所以：公历日期 = 2024-05-22

最终结果

农历2024年四月十五 = 公历2024年5月22日

示例三：天干地支推演（八字完整计算）

任务：计算2024年5月8日10:30（公历）的八字

第一步：年柱

公式：年干 = (年份 - 4) % 10
      年支 = (年份 - 4) % 12

年干 = (2024 - 4) % 10 = 2020 % 10 = 0 → 甲
年支 = (2024 - 4) % 12 = 2020 % 12 = 4 → 辰

年柱：甲辰

第二步：月柱

步骤1：确定月支
5月 → 辰月（固定对应）

步骤2：确定月干
公式：月干 = (年干序号 × 2 + 月份) % 10
年干甲 = 0
月干 = (0 × 2 + 5) % 10 = 5 % 10 = 5 → 辰月 = 5

查表：辰月对应丙
月柱：丙辰

第三步：日柱

步骤1：计算目标日期的儒略日
a = (14 - 5) / 12 = 0
y = 2024 + 4800 - 0 = 6824
m = 5 + 12*0 - 3 = 2
JD = 8 + (153*2 + 2)/5 + 365*6824 + 6824/4 - 6824/100 + 6824/400 - 32045
  = 8 + 61 + 2490760 + 1706 - 68 + 17 - 32045
  = 2460439

步骤2：计算天数差
基准JD = 2451545（2000-01-01为庚辰日=36）
天数差 = 2460439 - 2451545 = 8894

步骤3：计算干支序号
干支序号 = (36 + 8894) % 60 = 8930 % 60 = 50

步骤4：查干支表
序号50 = 辛亥

日柱：辛亥

第四步：时柱

步骤1：确定时支
10:30 → 巳时（9-11点，时支序号=6）

步骤2：确定时干
五鼠遁口诀"丙辛从戊起"：子时天干=戊
顺推至巳时（第6个时辰）：戊子→己丑→庚寅→辛卯→壬辰→癸巳
第6位时干 = 癸

时柱：癸巳

最终结果

公历2024年5月8日10:30的八字：
年柱：甲辰
月柱：丙辰
日柱：辛亥
时柱：癸巳

完整八字：甲辰年 丙辰月 辛亥日 癸巳时

示例四：闰年判定与星期计算

任务：判断2032年是否闰年，并计算3月1日是星期几

第一部分：闰年判定

判定条件：
(年份能被4整除 且 年份不能被100整除) 或 (年份能被400整除)

2032 ÷ 4 = 508（整除）✓
2032 ÷ 100 = 20.32（不能整除）✓

结论：2032年是闰年

第二部分：星期计算（蔡勒公式）

目标：2032年3月1日

q = 1（日期）
m = 3（月）
Y = 2032（不是1月或2月，不需要调整）

K = Y mod 100 = 32
J = Y / 100 = 20

h = (q + ⌊13(m+1)/5⌋ + K + ⌊K/4⌋ + ⌊J/4⌋ - 2J) mod 7
  = (1 + ⌊13×4/5⌋ + 32 + ⌊32/4⌋ + ⌊20/4⌋ - 40) mod 7
  = (1 + ⌊52/5⌋ + 32 + 8 + 5 - 40) mod 7
  = (1 + 10 + 32 + 8 + 5 - 40) mod 7
  = 16 mod 7
  = 2

h = 2 → 星期一

验证：查日历，2032年3月1日确实是星期一 ✓

示例五：闰月年的公历转农历

步骤1：查表

2020年春节 = 2020-01-25
2020年编码 = 0x1652c

解析编码：
闰月 = (0x1652c >> 12) & 0xF = 0x1 = 1 → 闰四月

每月天数：
正月: 30天

闰四月: 30天

步骤2：计算距春节天数

2月：29天（2020为闰年）

4月：30天

常见问题解答

Q1：如何判断某年是否有闰月？

答：查看该年的农历编码：

闰月 = (编码 >> 12) & 0xF
如果结果为0，则无闰月；如果为1-12，则闰对应月份

Q2：闰月的月名如何表示？

答：闰月沿用上月月名，如：

• 闰四月 → "闰四月"

• 闰五月 → "闰五月"

• 闰六月 → "闰六月"

Q3：公历日期在春节前，如何确定农历年？

答：

如果 公历日期 < 当年春节日期：
    农历年 = 公历年份 - 1
否则：
    农历年 = 公历年份

Q4：蔡勒公式中1月和2月如何处理？

答：将1月视为上一年的13月，2月视为上一年的14月，同时年份减1。

示例：2024年1月15日

m = 13（视为13月）
Y = 2023（年份减1）

Q5：天干地支60年一循环，从哪年开始算起？

答：公元4年是甲子年（甲子 = 序号0）

验证：

(4 - 4) % 60 = 0 → 甲子 ✓
(2024 - 4) % 60 = 2020 % 60 = 0 → 甲子 ✓

Q6：如何计算两个日期之间的天数？

答：

总天数 = 365 × 年份差 + 闰年数 + 日期差

闰年数 = 包含在年份差中的闰年数量
       = (目标年前一年/4 - 目标年前一年/100 + 目标年前一年/400)
       - (基准年前一年/4 - 基准年前一年/100 + 基准年前一年/400)

Q7：为什么农历年的天数不固定？

答：农历以月亮周期（朔望月，约29.53天）为基础，12个月约354天，需要通过闰月来匹配回归年（约365.24天），所以农历年有353-385天不等。

Q8：节气是如何划分的？

答：节气根据太阳在黄道上的位置划分：

• 春分点 = 黄经0°

• 每隔15°一个节气

• 共有24个节气

• 奇数位节气：中气（通常出现在月中）

• 偶数位节气：节令（通常出现在月初）

Q9：如何使用儒略日进行日期计算？

答：

1. 将日期转换为儒略日
2. 对两个日期的儒略日做减法得到天数差
3. 天数差 mod 7 得到星期偏移
4. 可用于跨年日期计算
