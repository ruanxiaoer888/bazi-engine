### 第二阶段：八字排盘与分析（定格局）

#### 第一步：手工排四柱（八字的骨架）

**排年柱**：绝对不能以正月初一为界，必须以"立春"交节为界。立春前为上一年，立春后为下一年。

**排月柱**：以二十四节气的"节"为界（惊蛰、清明、立夏等）。按照五虎遁口诀推算月干。

> 甲己之年丙作首，乙庚之岁戊为头，  

> 丙辛之年寻庚上，丁壬壬寅顺水流，  

> 若问戊癸何处起，甲寅之上好追求。

**排日柱**：从万年历抄下当天的日干支。

**排时柱**：时辰地支固定，时干按五鼠遁口诀推算。

> 甲己还加甲，乙庚丙作初，  

> 丙辛从戊起，丁壬庚子居，  

> 戊癸何方发，壬子是真途。

**验证**：用五虎遁验证月柱、用万年历交叉验证日柱、用五鼠遁验证时柱。

**【图表输出】八字四柱排盘表**：完成四柱排盘后，立即使用Visualizer生成八字四柱排盘表SVG图表。图表必须包含：年柱/月柱/日柱/时柱四列，每列标注天干地支、十神、藏干、纳音，日柱用高亮边框标注"日主"。详见可视化输出规范.md「2.1 八字四柱排盘表」。

#### 第二步：安十神与藏干（八字的血肉）

**立日主**：将日柱的天干圈起来，写上"日主/我"，这是客户本人的代表。

**地支藏干**：写出四个地支里面隐藏的天干。

> 子藏癸水在其中，丑癸辛金己土同，  

> 寅藏甲木和丙戊，卯中乙木独相逢，  

> 辰藏乙木兼戊癸，巳中庚金有丙戊，

**排十神**：根据"生我者印枭，我生者食伤，克我者官杀，我克者正偏财，同我者比劫"的原则，把其他七个字（加上藏干）全部标上十神。

#### 第三步：手工推排大运（人生的轨迹）

**定顺逆**：阳男阴女顺排，阴男阳女逆排。（阳男指年干为甲/丙/戊/庚/壬的男性）

**算起运岁数**：

- 顺排者：从出生日，数到下一个节气的交节时间
- 逆排者：从出生日，倒数到上一个节气的交节时间
- 折算公式：3天 = 1年，1天 = 4个月，1个时辰 = 10天

**排大运干支**：以月柱为基准，顺排或逆排。排满8步大运（每步管10年）。

#### 第四步：判旺衰与定格局（分析的灵魂）

这一步是决定算命准不准的核心，无法靠公式，全凭心法：

**得令**：看日主生在这个月，旺不旺？（如甲木生在春季寅卯月为旺）

**得地**：看日主在其他四个地支里，有没有根基（如甲木见寅卯辰未）

**得势**：看天干有没有其他比劫（同类）或印星（生我的）来帮扶

**定格局**：月支本气透出天干者，直接取格（如月支藏正官并透出天干，为正官格）

*参考古籍：《渊海子平》、《子平真诠》（专讲格局）*

#### 第二步：命盘架构解读（紫微的骨架）

**1. 命宫与身宫（人格核心）**

- **命宫**：先天性格、人格特质、一生格局高低
- **身宫**：后天发展、中年以后重心、实际行为模式

*解读原则*：命宫主星决定"我是谁"，身宫主星决定"我后来变成了谁"。命宫身宫同宫者，先天后天一致；不同宫者，中年后有明显转变。

**2. 三方四正（格局判断）**

以命宫为基准，看：

- **三方**：财帛宫、官禄宫（事业宫）、迁移宫
- **四正**：命宫 + 三方 = 四正

*判断逻辑*：主星在三方四正的分布决定格局层次。紫微天府坐命，三方见左辅右弼、天魁天钺，为上格；煞星云集，破格。

**3. 十四主星落宫解读**

参考知识库中十四主星详解，分析命宫、身宫及三方四正主星组合。

**十二宫逐宫详批标准格式**：

每个宫位按以下维度展开分析，用表格呈现：

```

| 维度 | 解读 |
|:---|:---|
| **主星本质** | 该主星在此宫位的核心特质（庙旺利陷决定吉凶程度） |
```

**批断顺序与重点**：

1. **命宫**（定格局）：性格特质、人生格局、先天运势总纲
   - 重点分析：命宫主星本质 + 煞星组合 + 命主星
   - 身宫同宫/不同宫的解读差异

2. **兄弟宫**：手足关系、合伙运势、母亲状况
   - 重点分析：主星性质决定手足亲疏，煞星多则各自独立

3. **夫妻宫**：婚姻状况、配偶特质、感情模式
   - 重点分析：主星看配偶类型，桃花星看异性缘，煞星看婚姻波折
   - **关键问题识别**：配偶是否强势、婚姻早晚、是否适合早婚

4. **子女宫**：子女缘分、学生下属、桃花偏财
   - 重点分析：主星看子女特质，煞星看教育难度

5. **财帛宫**：求财方式、理财能力、财运起伏
   - 重点分析：主星看财源性质（正财/偏财/技术财），四化看财运动态
   - **太阴/武曲/天府/贪狼**等财星入财帛宫的差异化解读

6. **疾厄宫**：健康状况、体质倾向、灾厄类型
   - 重点分析：**紫府/天梁等吉星坐疾厄=身体底子好**，煞星多则注意对应系统
   - 结合五行属性推导健康风险方向

7. **迁移宫**：外出运势、人际关系、社会形象
   - 重点分析：外出发展吉凶、在外地 vs 老家的发展差异
   - **与八字喜用方位交叉验证**

8. **仆役宫（交友宫）**：朋友质量、下属助力、人际小人
   - 重点分析：交友圈子质量、合作伙伴靠谱程度

9. **官禄宫（事业宫）**：事业发展、工作性质、成就高低
   - 重点分析：**此宫为人生成就的核心指标之一**
   - 太阳/紫微/天府/天相等事业星入官禄的差异化解读
   - 四化入官禄宫的动态分析（化禄=名利双收，化权=掌权，化科=名声，化忌=压力）

10. **田宅宫**：房产运势、家庭环境、不动产
    - 重点分析：置产时机（早/晚）、祖业能否继承

11. **福德宫**：精神世界、兴趣爱好、祖上积德
    - 重点分析：**此宫揭示内心真实状态**
    - 化忌入福德 = 精神内耗、焦虑、完美主义倾向
    - 煞星多则内心不宁静

12. **父母宫**：父母关系、长辈助力、学业文书
    - 重点分析：与父母亲缘深浅、长辈能否提供助力

### 13.2 图表穿插位置（强制）

> **技术说明**：`show_widget` 工具生成的 SVG 图表在对话界面中是以**独立消息卡片**形式呈现的，无法像 Markdown 图片一样物理嵌入到一段文字消息内部。因此"穿插"是指在**对话流程中交替出现**，而非文字与图表合并为同一条消息。执行时必须严格遵守以下分段交替顺序：

| 图表名称 | 穿插位置 | 执行顺序 |
|:---|:---|:---|
| **八字四柱排盘表** | 紧接在"2.1 四柱确认"文字输出之后、"2.2 格局分析"之前 | 先输出 2.1 文字 → 调用 show_widget → 再输出 2.2 文字 |
| **五行力量分布图** | 紧接在"2.4 五行力量分布"小标题及引导文字之后 | 先输出 2.4 开头文字 → 调用 show_widget → 再输出 2.4 结论文字 |
| **十神关系图** | 紧接在"2.2 格局分析"之后（如需要） | 先输出 2.2 文字 → 调用 show_widget → 再输出 2.3 文字 |
| **紫微十二宫格图** | 紧接在"3.2 紫微十二宫格图"小标题之后、"3.3 关键宫位详批"之前 | 先输出 3.2 文字 → 调用 show_widget → 再输出 3.3 文字 |
| **大运流年时间线** | 紧接在"2.5 八字分项断事"中大运分析文字之后 | 先输出大运分析文字 → 调用 show_widget → 再输出后续文字 |

**核心原则（必须遵守）**：
1. **禁止集中生成**：绝对禁止先一次性输出全部文字，再集中调用所有 show_widget；也禁止先集中调用所有 show_widget，再输出文字。
2. **分段交替**：文字段落与图表卡片必须在对话中**交替出现**。一段文字 → 一个图表 → 下一段文字 → 下一个图表。
3. **图表紧跟上下文**：每个图表必须紧跟在其对应分析小标题的文字之后出现，两者之间不得插入其他主题的文字。
4. **图表后紧跟解读**：图表卡片之后，必须立即输出 2-3 句针对该图表的文字解读，再进入下一段分析。
