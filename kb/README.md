## 使用约定

1. **排盘**：用确定性代码（lunar-python 等）计算四柱/大运/流年，不要依赖 LLM 心算。
2. **论命**：先查 01-basics 确定干支十神，再按 02-rules 判定旺衰/格局/用神，最后从 03-classics 引用依据。
3. **断语**：每条输出必须标注出处（如《穷通宝鉴》《滴天髓》），未命中规则的不得强行断语。
4. **免责**：所有分析仅供传统文化参考，不构成决策依据。

## 排盘引擎（ui/index.html）

可视化排盘界面，单文件离线可用，数据全部内联（节气表 + 断语库）。

**排盘算法**
- 年柱：以**立春精确时刻**为界（lunar-python 天文计算生成 1895–2100 节气表）
- 月柱：以**十二节**精确时刻为界（立春→寅月 … 大雪→子月），五虎遁起月干
- 日柱：公历天数差 + 基准（1900-01-01 = 甲戌），Date.UTC 精确递推
- 时柱：五鼠遁 + **晚子时**规则（23:00 后按次日日干起甲子时）
- 真太阳时：内置主要城市经度表，按 `(经度−120°)×4 分钟` 校正后重排
- 大运：年干阴阳 + 性别定顺逆排，起运岁数 = 出生距最近节天数 ÷ 3，递推 8 步
- **五行分布**：藏干加权（天干1.0；地支本气1.0/中气0.5/余气0.25；月令×1.5）
- **身强身弱**：帮扶（比劫+印）vs 克泄耗（食伤+财+官杀）比例，>0.6 强 / 0.4–0.6 中和 / <0.4 弱；据此推**喜用神**与**月令取格**
- **断语匹配**：`matchRules()` 支持 日主 / 旺衰 / 十神 / 五行(旺弱中和) / 状态(桃花/调候) / 性别 / 位置(日支·年月·日时) / 组合 / 格局
- **流年分析**：输入目标年 → 流年干支、十神、与原局四柱地支的冲/合/刑/害/三合、天干五合、与所选大运的关系
- **流月分析**：输入目标年 → 十二流月柱（按节气分界）、纳音、十神（对日主）、与命局四柱合/冲/半合关系、调候月运简述
- **合婚配对**：双盘排盘 → 七大维度加权评分（日柱关系25/五行互补25/纳音10/十神15/生肖10/大运10/用神5），输出总分与综合评级
- **神煞**：24 项核心吉凶星曜按查法表计算（天乙/文昌用年干+日干；天德/月德用月支干支混合；驿马/桃花/华盖/将星/劫煞/亡神/灾煞用年支+日支；孤辰/寡宿/岁破/红鸾用年支；羊刃/禄神/学堂/金舆/流霞用日干；勾绞/天罗地网用年支+性别），仅显示命局实际出现的神煞并标注所在宫位，按 吉/凶/中 分组
- **五行补救**：基于喜用神（`xiYong`）从《五行补救方案》映射 颜色/方位/数字/行业/饰品/饮食 建议；身强/弱直接用喜用神，身中和取最弱五行做微调，并注明"以喜用神为准，非缺什么补什么"

**校验**：算法与 lunar-python 逐项对比（节气精确时刻口径），并以 `八字命理/新历农历对照表.xlsx` 每日干支交叉验证；`tools/test_ui.js`（node 运行）覆盖四柱/晚子时/立春界/真太阳时/藏干五行/断语匹配/流年/合婚/纳音表，全部 PASS。

**构建**：`tools/build_ui.py` 读取 `ui/jieqi.json` 与 `kb/04-rules-db/rules.json`，注入 HTML 模板生成 `ui/index.html`（单文件）。断语库扩展用 `tools/gen_rules.py`（生成后重跑 build_ui.py）。修改后校验：先 `build_ui.py` 再 `node test_ui.js`。
