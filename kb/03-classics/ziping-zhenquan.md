# 《子平真诠》用神专论（摘录与注疏）

> 来源：《子平真诠》（清·沈孝瞻）。本篇为知识库"用神"核心依据，供论命第三阶段"取用神、定格局"引用。
> 正文【原文】为典籍要句，【注】为白话疏解。主要素材已与本地古籍原文《子平真诠》交叉核对。

## 一、用神总纲：专求月令

【原文】"八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉。"

【注】用神是八字中最关键、最能扶抑日主或成格的那个字。取用神首重月令（出生之月地支），因为月令是四季旺气所在，力量最重（"十分力气占五分"）。日干配上月令地支的生克关系，就分出格局。

### 月令优先原则
1. 用神首重月令，月令为"本家自有"的内格，如树之根本
2. 月令无可用之物，才于其他干支另寻用神（外格）
3. "月令，本也；外格，末也"——先看月令，后看外格

## 二、格局判定：以月令透干定格

- 月令**主气透出天干** → 以该十神定格局
- 主气不透 → 看中气、余气是否透干
- 月令无可用之物 → 方看其他干支取外格

### 八格体系（财官印食杀伤枭刃）

| 格局 | 成立条件 | 意象 |
|------|---------|------|
| 正官格 | 月令正官透出 | 仕途、地位、名誉 |
| 七杀格（偏官格） | 月令七杀透出 | 魄力、风险、权力 |
| 财格（正/偏） | 月令财星透出 | 财富、物质 |
| 印格（正/偏） | 月令印星透出 | 学历、权力、房产 |
| 食神格 | 月令食神透出 | 才华、寿元、表现 |
| 伤官格 | 月令伤官透出 | 艺术、创新、叛逆 |
| 建禄格 | 月令为日主之禄 | 日与月同，另寻财官食透干 |
| 月劫格 | 月令为劫财 | 同上，另寻用神 |

## 三、格局顺用与逆用（核心法则）

【原文】"财官印食，此用神之善而顺用之者也；杀伤枭刃，此用神之不善而逆用之者也。当顺而顺，当逆而逆，配合得宜，皆为贵格。"

### 吉神顺用（宜生扶保护）
- 正官 → 喜财生、印护
- 正财 → 喜食伤生、官杀护
- 正印 → 喜官杀生、比劫护
- 食神 → 喜比劫生、财星泄

### 凶神逆用（宜制化）
- 七杀 → 食神制杀、印星化杀
- 伤官 → 印星制伤、财星泄伤
- 偏印（枭） → 财星制枭
- 劫财 → 官杀制劫

## 四、格局成败

### 成格条件
- 用神透干通根，有"相神"辅助（如正官格配财印）
- 吉神得生扶，凶神得制化
- 格局清纯不杂

### 败格条件
- 用神被冲、被克、被合（"用神不可伤"）
- 吉神被伤，凶神无制
- 格局驳杂，用神真假不分

【原文】"如月令有杀，不可置杀不论而另取他格；月令有官，不可另取日禄归时格。"——月令既定，当顺其气，不可舍本逐末。

## 五、用神层次（真/假/纯/杂）

- **用神真**：月令主气透干有力 → 格局层次高
- **用神假**：月令中气/余气透干，主气不透 → 格虽成，层次低
- **用神纯**：用神单一明确 → 格局清贵
- **用神杂**：用神驳杂 → 格局层次降

## 六、建禄月劫格的特殊处理

【原文】"如木生寅卯，日与月同，本身不可为用，必看四柱有无财官煞食透干会支，另取用神；然终以月令为主，然后寻用。"

【注】日主坐禄（如甲生寅月），月令即是日主自身，不能作"用"，须看他柱有无财官食伤透出，另取用神，但仍以月令为根基。

## 七、取格常见错误（警示）

1. 月令有杀当论杀，不可置杀不论而另取他格
2. 月令有官当论官，不可另取日禄归时格
3. 月令有财当论财，不可另取拱贵夹贵格
4. 财格逢时杀为"财生杀"破格，不可作时上偏官格
5. 月令有暗官不可作刑合格
6. 月令建禄用官，不可作拱格

> 引用格式示例：《子平真诠》"用神专求月令"；《子平真诠》八格·顺逆用。
