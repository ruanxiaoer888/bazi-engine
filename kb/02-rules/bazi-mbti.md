## 一、为什么可以做类比

十神描述的是**人在关系中的行为模式**：面对压力时是靠规则还是靠人情、面对财与权是争夺还是配合、表达是外放还是内收。
人格类型学描述的是**认知与决策偏好**。两者都不评价能力高低，都只讲"倾向"，所以可以做**有限度的类比**。

限度在哪里：十神来自命局结构，讲的是"你在什么位置上容易有什么反应"；
人格类型来自自评量表，讲的是"你怎么感知与判断"。**同一套倾向可以对应多种类型，反之亦然**——所以本文全部映射都是"常见倾向"，不是判定。

## 二、四组维度与本项目的类比口径

| 维度（通俗含义） | 一端 | 另一端 | 八字侧常用来类比的要素 |
|---|---|---|---|
| 能量指向（向外 / 向内） | 外放、先行动 | 内收、先观察 | 阳干偏外放、阴干偏内收；比劫外显、印星内蓄 |
| 信息接收（具体 / 抽象） | 重实感、看细节 | 重联想、看整体 | 食伤偏具象表达与实操；印星、华盖偏抽象与概括 |
| 决策依据（事理 / 人情） | 就事论事、讲规则 | 顾及关系、讲体面 | 官杀偏规则与目标导向；印星、食伤偏人情与感受 |
| 生活节奏（结构 / 弹性） | 计划性强、喜收口 | 随机应变、留余地 | 正官正印偏结构；伤官劫财偏弹性 |

> 用法：**只把对应上的那一两项讲出来**，不要四项全塞进一段话——四项全中等于什么都没说。

## 三、十神 → 行为倾向速查（本项目原创整理）

| 十神 | 常见行为倾向 | 通俗类比（非类型判定） |
|---|---|---|
| 比肩 | 独立、自我驱动，不轻易借力 | 倾向"我来做"的独立型 |
| 劫财 | 敢争敢抢、行动快，边界感偏弱 | 倾向竞争驱动的行动型 |
| 食神 | 温和表达、享受过程、节奏舒缓 | 倾向体验导向的表达型 |
| 伤官 | 表达欲强、讲创意、不受旧框 | 倾向创意与破格型 |
| 正财 | 务实、按部就班、重积累 | 倾向稳健执行型 |
| 偏财 | 机会敏感、善交际、愿冒险 | 倾向机会捕捉型 |
| 正官 | 守规则、重责任、讲程序 | 倾向秩序与责任型 |
| 七杀 | 抗压强、目标导向、行动果断 | 倾向压力驱动的攻坚型 |
| 正印 | 重学习、讲情面、偏内省 | 倾向内省与支持型 |
| 偏印 | 思维跳脱、专精冷门、独立性高 | 倾向专精与独思型 |

补充：**十神要结合旺衰与位置看**。同为正官，身强时是"能扛事"，身弱时是"被压着"；
同为伤官，有制化时是"才华有出口"，无制时是"言语易伤人"。**不要脱离命局结构单独引用本表。**

## 五、使用边界（写报告时必须遵守）

1. **不得输出 MBTI 类型码**（如"你是 INTJ"），只能写"倾向"；
2. **不得用于评价能力、智力、心理健康**；
3. 涉及求职、升学、婚恋时，只能表述为"沟通风格差异"，不得作为建议依据；
4. 每段类比之后应有一句常识性提醒：**人格倾向会随经历与年龄变化，标签只作沟通用语**；
5. 本文不进入发布/商业交付包（见 `THIRD-PARTY.md` 与 `tools/build_release_zip.py`），仅供仓库内参考与报告措辞。
