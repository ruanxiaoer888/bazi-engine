# ENGINE-CHANGES.md — 引擎变更权威记录

> **用途**：bazi-engine 引擎（`engine/engine.dist.js` 及其源码 `tools/build_ui.py` ENGINE 标记区）每次变更的唯一权威记录。
> **给谁读**：① 本仓库新会话（对齐版本）② **bazi-app 对话**（C 端依赖本引擎，读此文件核对版本/MD5、判断是否需要回归）。
> **约定**：
> - 每次引擎变更 → 在下方**顶部**追加一条记录，并 **bump 版本号**（SKILL.md frontmatter `version` + dist 头注释）。
> - `影响C端` 列：`是` = bazi-app 需回归对应功能；`否` = 纯 UI/输入侧，dist 未变或行为不变。
> - 交付动作：`cp engine/engine.dist.js ../bazi-app/web/engine.dist.js`（只拷贝，commit 由 bazi-app 对话自行处理）。
> - 新增记录含当次 dist 的 MD5，bazi-app 侧 `md5sum web/engine.dist.js` 与下表核对，不一致即引擎有更新。
