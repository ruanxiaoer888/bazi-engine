## 2. 基础链路回归（冒烟）

1. 农历输入：如 2024-01-01（腊月初一）→ 排盘成功、农历↔公历互转正确
2. 阳历输入：1990-05-15 10:00 广州 → 四柱庚辰金边（与 bazi-engine 验收案例一致）
3. 真太阳时开/关切换 → 排盘结果随之变化（北京时 vs 真太阳时）
4. 无任何面板空白（每类至少输出 1 条断语，见 §3 兜底检查）

## 3. 面板级回归（重点）

**判定**：C 端同盘实测应落在 ±10 内（C 端若对 ctx 做了后处理/过滤，允许更少但不允许 0 面板空）；若差异 >20 条 → 检查 C 端是否误用了旧 RULES 或过滤逻辑过严。

### 3.2 每面板检查点

| 面板 | 检查点 |
|---|---|
| 性格 | 含日主断语 + 神煞性格（如带文昌盘出现「文雅喜读书」） |
| 事业 | 含十神/位置/格局断语；带文昌/禄神盘出现对应事业断语 |
| 财运 | 含正偏财/食伤生财/身强财透断语 |
| 婚姻 | 男命含妻星断语、女命含夫星断语；日支坐桃花盘出现「墙内桃花」 |
| 健康 | **合规抽查**：全部为「提示/宜注意」措辞 + 附就医建议，**不得出现疾病确诊式断言** |
| 格局 | 特殊格局盘（专旺/从格）出现细分格局断语；普通盘含 10 格断语 |
| 用神喜忌 | 中和盘喜忌空（显示「—」）；强弱盘喜用/忌用结构合理 |
| 神煞 | 带神煞盘逐项输出；**日支逢空亡盘应出现空亡断语**（v1.2.2 修活） |
| 学业/六亲/十神组合 | 非空即可，抽查 1-2 条出处可追溯 |

### 3.3 渲染兜底

- 同文案去重生效：同一盘内无重复断语刷屏（引擎渲染层有去重，C 端如有自渲染也建议过一遍）

## 5. 报告生成与排版回归

1. **篇幅**：单盘 60~85 条断语 → 报告页数/滚动长度显著增加，确认：
   - 无固定高度容器被撑爆/截断
   - 分页/打印不跨栏错乱
   - 移动端滚动流畅
2. **海报分享**：若海报含断语，确认文本不溢出图片边界（建议按最长盘 85 条做压力测试）
3. **性能**：报告组装耗时无明显劣化（断语 1000 条匹配为纯循环，量级无虞，确认即可）
4. **去重**：同文案不重复出现（引擎兜底 + C 端渲染）
